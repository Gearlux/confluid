# Confluid bug report — 2026-08-13 hunt

Every bug below is **confirmed by running the reproduction shown** (outputs pasted verbatim,
loggair banner stripped). Each entry: the use case, the complete runnable example, the measured
actual output, and the expected behaviour with the mandate/doc it violates. Run any example with
`/Users/gert/taidal/.venv/bin/python script.py` from an empty directory.

**Glossary (read this first):**
- **`Target`** — confluid's recipe class. `Target(Engine, power=5)` is NOT an Engine; it is a note
  saying "build `Engine(power=5)` later". Every YAML `_target_:` mapping parses into one. It was
  named `Class`/`Instance` until the 2026-08-11 merge-and-rename that matched it to the `_target_`
  key. Production code almost never writes it by hand.
- **`PartialClass`** — the deferred variant of the same recipe: "build it even later, when I hand
  you the missing argument" (`flow(self.optimizer, params=model.parameters())`). This is the form
  production code actually writes (14 body slots in matrainer alone).
- **marker** — any such recipe object sitting in a config tree.
- **the load path** — what happens inside `load()` / `materialize()`: parse YAML, resolve, build.
- **the configure path** — `configure(obj, config=...)`: apply a document to objects that already
  exist.

Severity: **S1** = silent wrong answer on a mainstream spelling · **S2** = silent wrong answer on a
plausible spelling · **S3** = crash/untyped error on legal input · **S4** = contract divergence with
narrow blast radius.

## P3 · S2 — A scope block at document ROOT leaks the raw `ScopeBlock` object out of `load()`

**Use case:** a small overlay file whose entire content is conditional
(`_notscope_: {ci: }` — "everything here except on CI").

or `elif scopes:`; a root `ScopeBlock` with `scopes=None` hits neither branch.

## I1 · S1 — Body slots assigned by tuple unpacking are invisible — a bare key silently does not land

**Use case:** an ordinary constructor unpacking a pair: `self.alpha, self.beta = compute_defaults()`.

```python
from confluid import Target, configurable, materialize

@configurable
class Normal:
    def __init__(self):
        self.alpha = 1
        self.beta = 2

@configurable
class Unpacked:
    def __init__(self):
        self.alpha, self.beta = 1, 2      # SAME two slots, tuple-assigned

for cls in (Normal, Unpacked):
    marker = Target(cls)
    obj = materialize({"obj": marker, "alpha": 99})["obj"]
    print(cls.__name__, "alpha after bare-key broadcast:", obj.alpha)
```
**Actual (measured):**
```
Normal alpha after bare-key broadcast: 99
Unpacked alpha after bare-key broadcast: 1     # the sweep key silently did nothing
```
Also invisible: `for self.idx in …:`, `with open(p) as self.stream:`, `self.head, *self.tail = …`.

**Expected:** both classes answer alike — `self.alpha, self.beta = …` declares the same body
slots as two plain assigns. This is the silent-config-drop class the report/B1 mandates exist to
kill. **Where:** `confluid/introspect.py:204-232` (`_self_attr` never unpacks `ast.Tuple`/
`ast.Starred` targets, `ast.For.target`, `ast.withitem.optional_vars`).
