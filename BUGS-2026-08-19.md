# Confluid bug report — 2026-08-19 hunt

Second adversarial review of confluid (the first is `BUGS-2026-08-13.md`, today pruned to its 31 open
findings; each of those was re-verified — see the status section at the bottom of this file). **Every entry below was confirmed by running the
reproduction shown** — the output is pasted verbatim (loggair banner stripped). Run any example with
`/Users/gert/taidal/.venv/bin/python script.py` from an empty directory (a few create helper files first — the
script says so).

**Method.** Seven independent line-by-line reviews, one per area (parse · scopes/refs · broadcast · engine ·
configure/dump/hydraide · introspection/validation · registry/decorators), each checking the code against the
contract in `docs/lifecycle.md`, the area's `docs/*.md`, and `AGENTS.md`. Each reviewer had to reproduce a
defect before reporting it; fourteen entries spread over all seven areas were then re-run independently
(SR1, SR3, R4, R9, R10, PA1, PA6, ENG-17, N1, N2, BC1, BC5, CD1, CD3) and all reproduced. Baseline at the start
of the hunt (commit `7c218f7`, clean tree): 1548 tests pass, all 25 `examples/*.py` run, mypy (workspace root) /
flake8 / black / isort green — none of the bugs below is caught by the existing gates.

**Glossary** — the same as `BUGS-2026-08-13.md`: *Target* = the recipe a `_target_:` mapping parses into;
*PartialClass* = the deferred recipe (`_partial_: true`); *marker* = any recipe object in a tree; *the load path*
= `load()` passes 1–9; *the configure path* = `configure(obj, config=…)` over live objects; *settled* = after
pass 7 (kwargs final, nothing built).

Severity: **S1** = silent wrong answer on a mainstream spelling · **S2** = silent wrong answer on a plausible
spelling · **S3** = crash / untyped or unlocated error on legal input · **S4** = contract divergence with narrow
blast radius (two paths or two spellings disagree; docs ≠ code; a missing file:line).

IDs: `PA`=parse · `SR`=scopes/refs · `BC`=broadcast · `ENG`=engine · `CD`=configure/dump · `N`=introspection ·
`R`=registry. Where two reviewers hit the same root from different sides the entry carries a **Same root as:**
line; exact duplicates were folded into one entry (PA3→SR2, PA16/ENG-13→SR5, SR9→PA10, R17→PA27, R8→N14,
BC18→ENG-2).
