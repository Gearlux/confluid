- [ ] **BC10 — a later root `'**'` rider loses to a node's own rider** @bugs — reopened 2026-11-03. Repro (`BUGS-2026-08-19.md`):
  ```yaml
  t: !class:Trainer
    '**': {wd: 0.5}                  # t's own rider
    optimizer: !class:Opt {lr: 1.0}
  '**': {lr: 9.0}                    # written last, should win
  ```
