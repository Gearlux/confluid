- [ ] **`lazy_param_names` scans `__init__` params but not `__init__`-body slots** @refactor — AGENTS rule 4 makes body slots (`self.optimizer = LazyClass(...)`) first-class configurable slots, and `to_pydantic` DOES scan them (`_post_init_field_specs` / `scan_init_body`), but `lazy_param_names` reads `get_type_hints(cls.__init__)` only. So `self.optimizer: Lazy[Optimizer] = LazyClass(...)` carries a marker nothing reads: liquifai's deep-flow keeps it deferred by the VALUE being a `LazyClass`, not by the annotation, and `lazy_param_names_of(cls)` reports an empty set for a class whose deferred slots all live in the body. Found 2026-07-29 while annotating a consumer's trainer — the annotation is still worth writing (it types the `to_pydantic` field, where `Any` typed nothing), but the asymmetry means the marker is load-bearing in one place and decorative in the other. Fix is to union the body scan into `lazy_param_names` the way `broadcast_attrs` is already unioned; the packaged-mode caveat (AST scan unavailable → bake) applies equally. @low
